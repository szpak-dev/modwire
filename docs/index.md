# Modwire documentation

Use this documentation to decide whether Modwire fits a repository, establish the
first executable architecture rule, and integrate its public CLI or Python API.

Start with [Check a polyglot project](tutorials/check-a-polyglot-project.md). Read
[The Modwire architecture convention](architecture/convention.md) before adapting the generated
configuration. Use the [how-to guides](how-to/index.md) for a specific task and the
[reference](reference/index.md) for exact contracts. The [glossary](reference/glossary.md)
defines Modwire's architecture and runtime vocabulary.

Before adopting Modwire, check [Language support and limits](reference/language-support.md).
For the production-project extraction record and the deliberately narrow traversal
benchmark, read [Recorded evidence](reference/evidence.md).
